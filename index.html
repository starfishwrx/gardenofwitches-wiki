Before the first room

Make four actions feel separate.

Move, aim, attack and dash in a low-pressure space before committing to a route. Keep Keyboard & Mouse when free aim feels natural. Try Keyboard-Only or Gamepad when the pointer competes with movement.

Stay with the default Scissors long enough to recognize its full combo and its unsafe moment. Your supporting Spell or Special Skill should create space for that moment, not start a second unrelated plan.

Frequently asked questions

What is Garden of Witches?

Garden of Witches is Team Tapas' PC action roguelike about Sil bringing witches back to the tea party through repeated combat runs.

How many Scissors are in version 1.0?

Official 1.0 materials name five routes: Scissors, Giant Scissors, Magic Scissors, Broken Scissors and Singing Scissors.

How long is the version 1.0 story route?

The confirmed structure is five main chapters followed by Epilogues 1, 2 and 3. Challenge Mode unlocks after Epilogue 3.

Are the builds on this wiki final tier rankings?

No. They are sourced interaction paths with verification steps. Use the 1.0 DPS display and repeatable runs before treating a route as a universal ranking.

A failed room is useful when it tells you whether the problem was input, route choice, damage uptime or survival. Write down that one failure before changing the loadout. If the next run improves the same symptom, keep the change. If not, restore the baseline.

New unlocks are choices, not automatic upgrades. Practice a new Scissors until you can perform its defining combo, charge or resource loop before comparing it with the default weapon.

Progress explained

Run power and permanent progress are different.

Imprints, Relics and other rewards assembled inside a run are temporary. Returning to Sil's House starts the next attempt without that exact stack. Level-based upgrades selected through the house progression system are permanent and should not silently disappear from the same save.

Version 1.0 launched with reports of permanent upgrade levels resetting after chapter or save transitions. The developer treated those reports as a bug investigation. If that is what happened, stop grinding, preserve the save and record before/after screens.

Diagnose an upgrade reset →
Fast distinction

Expected: the in-run build starts over.

Not expected: spent permanent nodes or character level vanish from the same save.
