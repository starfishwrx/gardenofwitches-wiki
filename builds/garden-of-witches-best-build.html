Garden of Witches Best Build for Version 1.0

Use Broken Scissors for a close-range Sharpness crit loop. Use Magic Scissors + Fireball for charge-based ranged pressure.

Direct answer

Best melee starting path: Broken Scissors + Rush + Cat’s Eye Ring, then choose Hunger or Frenzy according to whether you can maintain Sharpness. Best ranged starting path: Magic Scissors + Fireball + Blue Chakram, then choose charge Imprints by single-target or multi-hit play.

These are official example interactions, not a claim that one fixed loadout wins every 1.0 run. The developer marked preview numbers as subject to change.

Random-reward fallback rules

A best-build page should survive the roguelike reward system. The priority list is not a promise that every named piece appears. When a preferred Imprint or Relic is absent, keep the primary action intact. Broken Scissors still needs repeated hits and a way back into range; Magic Scissors still needs safe charging and a useful release line. Replace the missing piece by function, not by name.

  1. Keep the selected Scissors and its input cadence.
  2. Protect the weakest moment: reconnecting for melee or creating space for charge.
  3. Prefer a reward that improves an action already present in the loop.
  4. Avoid a conditional bonus whose trigger the loadout cannot produce.
  5. Re-evaluate only after the next comparable encounter.

DPS comparison method

Version 1.0 adds a real-time DPS display, but a single peak number does not prove a build. Use the same chapter, encounter type and difficulty. Keep the Scissors, Spell and Special Skill fixed. Change one Imprint or Relic, then record the sustained DPS window, clear time and damage taken. Repeat at least once because enemy movement and random rewards can distort one attempt.

Run plan from Armory to result

Before leaving Sil's House, write the build in four jobs rather than four names: primary damage, safe approach, payoff and fallback. For Broken Scissors, the weapon owns primary damage, Rush handles approach and the crit window is the payoff. For Magic Scissors, the charged weapon creates the setup, movement creates time and Fireball spends the payoff. This job map makes random rewards easier to judge.

During early rooms, do not measure a route by how many colored upgrades it has. Ask whether the next reward makes the core input more available or more reliable. A reward that adds damage only after an unused trigger is weaker than a modest reward that lets the player finish another combo, hold another charge or stay inside Sharpness range.

Before a boss or durable target

  • Enter with the movement action available instead of spending it on a nearly defeated enemy.
  • Know which visible state proves the engine is ready: full Sharpness, a completed charge threshold or the confirmed resource indicator.
  • Keep one exit path. Peak DPS is not useful when the entire setup ends in avoidable damage.
  • Use the first safe cycle as a measurement. If the setup fails, change timing before blaming the component list.

Build record minimum

For a reusable result, record version 1.0, the chapter and difficulty, every Armory slot, selected Imprints and Relics, and one changed component. Capture a current tooltip when a previewed effect matters. An uncut combat sample should show setup, payoff and recovery. This prevents a lucky burst, different modifier or easier room from becoming a universal claim.

The best build is therefore a verified decision process: choose the executable rhythm, assemble functional jobs, adapt to drops and compare one variable. Future balance evidence can update a component without rewriting the entire player workflow.

Frequently asked questions

What is the best build in Garden of Witches 1.0?

There is no proven universal best build yet. The strongest documented starting paths are Broken Scissors with Sharpness support for close-range critical attacks, and Magic Scissors with Fireball for charge-based ranged play.

Are Early Access builds still valid in version 1.0?

Not as written. Version 1.0 removed Attribute, Synergy and Rune systems and redistributed their functions across Scissors, Spells, Imprints and Relics.

How should I compare builds?

Use the real-time DPS UI added in version 1.0, then compare the same chapter and encounter while changing one component at a time.
