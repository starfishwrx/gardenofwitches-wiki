Garden of Witches Upgrades Reset? Progress Guide

Tell a normal roguelike run reset from missing permanent Tapestry progress, then preserve the evidence needed for a real save bug.

Direct answer

In-run power resets normally: the Imprints, Relics and reward stack assembled during one attempt do not become the next run's starting build. Permanent house upgrades should persist: if spent Tapestry nodes or character level return to zero on the same save, current 1.0 reports treat that as a bug, not intended progression.

Do this before playing more

  1. Do not overwrite or delete the affected save.
  2. Open the same save slot and photograph the level and Tapestry state.
  3. Record the last chapter transition and whether another slot was loaded.
  4. Check the pinned known-bugs thread and the current game version.
  5. Report the before/after state instead of grinding replacement points.

The exact menu label can differ by version or localization. The practical distinction is where the choice belongs. If it was earned and selected as part of one chapter attempt, expect the run to rebuild. If it belongs to the save's house progression, it should not silently vanish after loading the same slot.

The older intentional reset is not the same issue

During the 0.9 system overhaul, Team Tapas replaced achievement-and-gold progression with a level-based system. The official notes warned that the migration would reset existing upgrades and return the new currency so players could select nodes again. That was a planned one-time conversion tied to a major update.

Version 1.0 launch reports describe a different symptom: players finishing Chapter 1, entering Chapter 2 or loading a slot and then seeing level or Tapestry upgrades return to zero. In the public thread, the Team Tapas community manager asked for save files and screenshots and escalated the issue to the developers. Do not explain that symptom away as normal roguelike design.

Five checks that protect the save

  1. Confirm the slot. Compare its timestamp and chapter with the slot used before the reset.
  2. Separate spent nodes from unspent points. Zero available points can mean they were spent; an empty node tree is a different symptom.
  3. Record the transition. Note whether the change appeared after a chapter clear, restart, game relaunch or loading another slot.
  4. Capture both screens. Include character level and the permanent upgrade interface. If an earlier screenshot exists, keep it unedited.
  5. Preserve the installation state. Record the displayed game version before updating, reinstalling or testing another branch.

Do not publish or upload save files to an unrelated public site. Use the official support path requested by Team Tapas. Save files can contain account- or device-linked details, and a public mirror does not help the developer reproduce the problem.

What can you safely do meanwhile?

Keep the affected save untouched until you have a copy or official guidance. If you continue playing, use a separate slot and record that choice. Avoid spending hours replacing permanent points before checking whether a hotfix or recovery instruction exists. Normal run learning—controls, room decisions and weapon practice—can continue on another slot without pretending the missing progression is expected.

If only Imprints, Relics or the route's temporary rewards disappeared after defeat, no recovery is required. Start the next run with a coherent Armory baseline, then rebuild from the new map. The reset guide exists to prevent these two very different cases from being confused.

Frequently asked questions

Do upgrades reset in Garden of Witches?

Temporary Imprints, Relics and other run rewards reset with the run. Permanent level-based upgrades selected in Sil's House should persist on the same save.

Why did my permanent upgrade level return to zero?

Players reported this after the 1.0 launch, and the Team Tapas community manager treated it as a bug investigation. Preserve the save, capture before/after screens and check the latest known-bugs thread.

Was any upgrade reset intentional?

An older 0.9 system migration intentionally reset prior upgrades so players could reselect them with the new level system. That one-time migration is different from current 1.0 permanent progress disappearing during normal play.
