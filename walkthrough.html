Garden of Witches Chapter Walkthrough: 1.0 Story Route

Clear Chapters 1–5 and Epilogues 1–3, checking Sil's House and the Armory between clears before entering Challenge Mode.

Direct answer

Complete Chapters 1–5, then Epilogues 1–3 on the same progressing save. Check the Armory after every clear because new skills can unlock through progress. After Epilogue 3, continue that cleared save to reach the Challenge Mode version of Sil's House.

Between chapters: five checks

  1. Return to Sil's House and make sure the latest clear saved.
  2. Open the Armory and inspect newly available Scissors, Spells and Special Skills.
  3. Read the current 1.0 tooltip before equipping an unlock.
  4. Change one loadout slot, not the whole build, when testing the new option.
  5. Keep the previous reliable loadout in mind so a weak experiment does not block the route.

The walkthrough does not assign unverified bosses, rooms or rewards to chapter numbers. The useful player need is the progression state: what to clear, what to inspect afterward and how to avoid continuing the wrong save.

After Epilogue 3

Challenge Mode is not a shortcut for unfinished story progress. The official sequence is: clear Epilogue 3, continue the cleared save, arrive in Challenge Mode Sil's House, prepare the build, then leave through the door. Use the dedicated Challenge Mode guide if the mode or entrance does not appear.

Version and source boundary

Team Tapas' official 1.0 notes confirm five main chapters, Epilogues 1–3, later skill unlocks and the Challenge Mode transition. Room sequences and run rewards remain variable; this route does not present guessed encounter details as fact.

Build continuity across the route

Do not replace a functioning loadout merely because a new item unlocks. Keep the old baseline, read the new tooltip and test one slot in the next comparable room. Chapter progress asks for reliable execution more often than a theoretical maximum assembled from unfamiliar parts.

Before each clear attempt, identify one failure from the prior run: interrupted combo, unsafe charge, missing range, weak group control or poor recovery. Change the slot that addresses that failure. After the attempt, check whether the symptom changed. This creates a useful progression record even when random rewards differ.

Save-state discipline

Use the most recent progressing save for Chapters and Epilogues. After Epilogue 3, preserve that cleared state and choose Continue. If the interface opens normal story Sil's House, verify the selected save before reinstalling or changing files. The official transition depends on progress state, not a secret menu combination.

Frequently asked questions

How many chapters are in Garden of Witches 1.0?

The official 1.0 route has five main chapters followed by Epilogues 1, 2 and 3.

What should I do after each chapter?

Return to Sil's House, inspect the Armory for new Scissors or Spells, read current tooltips and keep the cleared save.

What unlocks after Epilogue 3?

Challenge Mode unlocks. Continue the cleared save to enter the Challenge Mode version of Sil's House.
